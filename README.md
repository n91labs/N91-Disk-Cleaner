\# N91 Disk Cleaner



N91 Disk Cleaner is a lightweight Windows utility designed to scan and remove temporary files, application caches, logs, and other unnecessary data.



The program is written in C++ and distributed as a standalone Windows EXE.



\## Features



\- Scan the system for unnecessary files

\- Display how much disk space can be recovered

\- Select individual cleanup categories

\- Remove temporary files, caches, and logs

\- Simple Windows graphical interface

\- Detailed operation log

\- No installation required



\## Download



Download the latest version from the \*\*Releases\*\* section:

\## How to use



1\. Download the latest EXE from Releases.

2\. Start the program.

3\. Allow administrator access if Windows requests it.

4\. Click \*\*Scan\*\*.

5\. Review the detected files and selected categories.

6\. Click \*\*Clean\*\* to remove the selected files.
